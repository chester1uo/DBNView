# DBNView 用户指南

DBNView 无需转换即可打开 Databento DBN 文件（`.dbn` 以及 zstd 压缩的 `.dbn.zst`，DBN 版本 1–3）。
本指南介绍安装、三个前端、筛选、图表、IV 曲面、快捷键和故障排查。

## 1. 安装

### 1.1 从克隆的仓库安装

需要 Python 3.9 或更高版本。

```bash
git clone https://github.com/chester1uo/DBNView.git
cd DBNView
python -m venv .venv
.venv/bin/pip install -e ".[gui,tui]"      # Windows: .venv\Scripts\pip install -e ".[gui,tui]"
```

| 可选依赖组 | 安装内容 | 用途 |
|---|---|---|
| （无） | `numpy`、`zstandard`（Windows 上另有 `tzdata`） | 引擎和浏览器界面（`dbnview-web`） |
| `gui` | `PySide6`、`pyqtgraph`、`PyOpenGL` | 桌面应用（`dbnview`） |
| `tui` | `textual`、`plotext` | 终端界面（`dbnview-tui`） |
| `all` | `gui` + `tui` | 两个交互式前端 |
| `dev` | `all` + `pytest`、`pyflakes`、`pyinstaller` | 开发和打包 |

安装后会生成三个命令，每个命令也可以用模块方式运行：

| 命令 | 模块方式 | 前端 |
|---|---|---|
| `dbnview` | `python -m dbnview` | 桌面应用 |
| `dbnview-tui` | `python -m dbnview.tui` | 终端界面 |
| `dbnview-web` | `python -m dbnview.web` | 浏览器界面 |

### 1.2 平台说明

- **macOS**：开箱即用。图表和 3D IV 曲面都支持触控板双指缩放。
- **Windows**：
  - 时区数据来自自动安装的 `tzdata` 包。
  - 远程文件使用系统自带的 OpenSSH 客户端（`ssh.exe`）。它不支持连接复用，所以每次列目录或打开文件都会建立新连接。
- **Linux**：桌面应用需要常见的 Qt xcb 库。以 Debian/Ubuntu 为例：

  ```bash
  sudo apt install libxkbcommon-x11-0 libxcb-cursor0 libegl1
  ```

  终端界面和浏览器界面都不需要这些库。

### 1.3 打包好的桌面应用

可以用 PyInstaller 构建独立的桌面应用（见 [development.md](development.md#8-打包)）：

- **macOS**：`dist/DBNView.app`。把它拖进“应用程序”文件夹。在 Finder 中右键 `.dbn` 或 `.zst` 文件时，
  可以在 **打开方式** 里选择它。
- **Windows 和 Linux**：`dist/DBNView/` 文件夹，其中有 `DBNView.exe` 或 `DBNView`。

打包后的应用只包含桌面前端。

## 2. 打开文件

- **桌面应用**：
  - 在命令行传入路径：`dbnview file.dbn.zst`。
  - 使用 **文件 → 打开文件…**（⌘O / Ctrl+O），把文件拖进窗口，或从 **文件 → 最近打开** 中选择。
- **终端界面**：`dbnview-tui file.dbn.zst`。
  - 如果传入目录，或不传参数（使用当前目录），会弹出文件选择器。之后按 `o` 可再次打开它。
- **浏览器界面**：`dbnview-web DIR_OR_FILE …`。页面里有一个文件浏览器，根目录就是传入的目录。

文件打开后，DBNView 先读取元数据头（dataset、schema、时间范围、symbology），然后立即开始扫描。

### 2.1 通过 ssh 读取远程文件

桌面应用和终端界面可以读取另一台机器上的文件，那台机器上不需要安装任何东西。

- **桌面**：使用 **文件 → 打开远程文件（ssh）…**（⇧⌘O / Ctrl+Shift+O）。
  1. 选择 SSH 配置。列表包括 DBNView 配置和 `~/.ssh/config` 中的 `Host` 条目，通配符条目会被忽略。
  2. 点 **+** 新增配置，或选中 `~/.ssh/config` 的主机后点 **编辑** 导入（地址、用户、端口、代理由 `ssh -G` 读出）。
     一个配置包括：
     - **登录**：名称、地址、端口、用户名。
     - **认证**：密钥（指定私钥文件，留空则用 OpenSSH 默认密钥和 `ssh-agent`）或密码。
     - **代理**：不使用；跳板机（`ProxyJump`：`~/.ssh/config` 别名或 `user@host:port`，多跳用逗号串联，例如
       `tokyo-ec2,hluo@localhost:2222`）；SOCKS5 或 HTTP CONNECT 代理（`host:port`，通过 `nc` 连接）；或自定义 `ProxyCommand`。
     - **日志与安全**：OpenSSH 日志文件及等级（`ERROR` … `DEBUG3`），以及首次连接是否自动信任主机密钥
       （`StrictHostKeyChecking=accept-new`，密钥变更时仍会拒绝）。
     - **测试连接** 会连一次，显示远程 `uname` 或 ssh 的错误信息。
  3. 输入或浏览到目录。双击文件夹进入，双击文件打开。
- **命令行**：使用 `ssh://HOST/ABSOLUTE/PATH` 形式的 URL，HOST 可以是 `~/.ssh/config` 别名或 DBNView 配置名称：

  ```bash
  dbnview ssh://myserver/data/databento/opra-20260102.cbbo-1m.dbn.zst
  dbnview-tui ssh://myserver/data/databento
  ```

`HOST` 可以是 `ssh` 能识别的任何写法，比如 `~/.ssh/config` 中的别名或 `user@hostname`。路径必须是绝对路径，
因为 `~` 不会被展开。

工作原理：

- 数据通过 `ssh HOST cat PATH` 以流的方式传输，在本机解码。
- ssh 以 `BatchMode=yes` 和 `ConnectTimeout=10` 运行，所以它使用你现有的密钥和 agent，从不询问密码。
- DBNView 自建配置保存在 `~/.config/dbnview/ssh_profiles.json`（Windows 使用 `%APPDATA%\dbnview`）。密码只在
  当前进程的内存中保存，退出后需要重新输入，不会写入配置文件或 SSH 日志。
- 密钥认证可指定私钥文件，留空时使用 OpenSSH 默认密钥和 `ssh-agent`。密码认证通过 OpenSSH 的
  `SSH_ASKPASS` 运行。SOCKS5 / HTTP 代理需要支持 `-X` 的 `nc`（macOS 自带；Linux 用 OpenBSD netcat；Windows 需另行安装）。
- 在 macOS 和 Linux 上，连接会复用 120 秒（`ControlMaster=auto`，控制套接字位于 `~/.ssh/dbnview-*`），
  所以先浏览目录再打开文件只用一个连接。
- 列目录和获取文件大小用的是 GNU `find -printf` 和 `stat -c`，所以远程机器应该是 Linux 主机。
- zstd 流无法随机定位，所以即使设置了时间筛选，扫描也总是从文件开头开始传输。对于特别大的远程文件，
  直接在服务器上运行 `dbnview-web` 通常更快（见[第 9 节](#9-浏览器界面)）。

## 3. 扫描

扫描会从头读取文件，应用筛选条件，并把符合条件的行保存在内存中。

- **行数上限**：默认 1,000,000（**最大行数** 字段）。达到上限后扫描停止，状态栏会提示文件没有读完。
- **扫描完整文件**（桌面）：达到行数上限后继续读取，使统计信息（计数、分布、最活跃品种、时间范围）覆盖整个文件。
  表格中最多仍只保留 **最大行数** 行。
- **扫描 / 停止**：桌面应用用 ⌘R / ⌘.（Windows 和 Linux 上为 Ctrl+R / Ctrl+.），终端界面用 `s` / `x`。
  在任意筛选字段中按 Enter 也会开始新的扫描。
- **速度**：约每秒 500–600 万条记录，取决于记录大小以及磁盘或网络速度。

图表、订单簿重建和 IV 快照都基于扫描已载入的行，只覆盖部分文件时会给出提示。IV 曲面还可以把文件流式读取到
你选择的时间点（见[第 7 节](#7-iv-曲面)）。

## 4. 筛选

所有筛选条件之间是 AND 关系，在新的扫描中生效。

| 筛选 | 含义 |
|---|---|
| symbol | 在文件的 symbology 映射中匹配 symbol，不区分大小写。输入文字后按 Enter 添加**子字符串**模式；选择建议项则添加**精确**模式。多个模式之间是 OR 关系。双击某个模式或按 Delete 可删除它。在终端界面中，用逗号分隔多个模式，并在模式末尾加 `$` 表示精确匹配（`ESZ6$`）。 |
| instrument_id | 用逗号或空格分隔的 id，与 symbol 的匹配结果合并。 |
| 起 / 止 | 时间范围。“起”包含在内，“止”不包含（时间格式见下文）。 |
| 时间字段 | `auto`（记录有 `ts_recv` 时用它，否则用 `ts_event`）、`ts_recv` 或 `ts_event`。仅桌面和浏览器界面有此项。 |
| action / side | 复选框，只在记录类型有这些字段时显示。仅桌面和浏览器界面有此项；在终端界面中请用 `where`。 |
| where | 对每条记录求值的安全表达式（见下文）。 |

**时间格式。** 时间按当前选择的显示时区解释。

| 输入 | 含义 |
|---|---|
| `09:30`、`09:30:15.250` | 文件起始日期当天的时刻 |
| `2026-01-02 09:30:00` | 日期和时间 |
| `2026-01-02T14:30:00Z` | UTC（末尾的 `Z`） |
| `1767364200000000000` | 自 epoch 起的原始纳秒数（任何超过 12 位的整数） |

小数部分最多精确到纳秒。

### 4.1 `where` 表达式

`where` 表达式由 Python 的 `ast` 模块解析，在整列 numpy 数据上求值，从不使用 `eval`。只允许下面列出的语法。

- **名称**：记录的字段名，例如 `price`、`size`、`side`、`bid_px_00` 或 `ask_sz_00`。
  - 价格字段是实际数值（浮点数），未定义的价格为 `NaN`。
  - 字符字段与单字符字符串比较：`side == 'B'`。
- **运算符**：
  - `and`、`or`、`not`
  - `+ - * / %`
  - `&` 和 `|`（按位运算）
  - `== != < <= > >=`，可以连写：`1 <= size < 10`
  - `in` / `not in`，后接元组或列表
- **函数**：`abs()`、`isnan()`。
- **缺少字段**：如果某种记录类型没有表达式用到的字段，这种类型的行都不匹配。

示例：

```text
size >= 10 and side == 'B'
ask_px_00 - bid_px_00 <= 0.05
action in ('T', 'F')
not isnan(price) and price > 450
(flags & 128) != 0
```

### 4.2 筛选与 MBO 订单簿

重建 MBO 订单簿需要该品种之前的全部消息。下面这些筛选条件可能会漏掉这类消息：

- **起** 时间
- action / side
- `where`
- 记录类型筛选

只要其中任何一项生效，订单簿重建就会显示警告。只按 symbol、instrument_id 或 **止** 时间筛选是安全的。

## 5. 桌面应用

窗口分为三个区域：

- **左侧面板**：文件信息（路径、大小、dataset、schema、DBN 版本、时间范围、stype、symbols、mappings）、
  筛选条件和扫描进度。
- **标签页**：表格、图表、统计、格式说明、IV 曲面。
- 右侧的 **详情面板**。

用 ⌘L 显示或隐藏左侧面板，用 ⌘I 显示或隐藏详情面板。

工具栏可以设置 **时区**（ET、CT、UTC、London、HKT、JST）和 **时间格式**：

- **日期+时间**
- **仅显示时间**
- **原始 ns**

这两项设置对所有地方都生效，并会被记住。

### 5.1 表格

- 行只在滚动到时才读取，所以数百万行也能保持流畅。
- 价格除以 1e9，未定义的值显示为 `—`。
- side 和 action 会着色，flags 会被解码。
- status、statistics 和 definition 记录中的代码会显示其官方含义。
- **字段说明**：把鼠标悬停在列标题上即可查看该字段的含义。
- **列**：
  - 右键单击列标题，或使用 **字段** 菜单，可以显示或隐藏列。
  - 可以选择 **全部显示**，或选择 **精简** 选项，隐藏 rtype、publisher、sequence 等字段。
- **跳转到时间**：在表格上方的输入框中输入时间（例如 `15:45`）后按 Enter。
- **导出 CSV**：⌘E 导出所有已载入的行，时间戳按当前时区写出。

### 5.2 详情面板

单击一行可以看到：

- **字段**：每个字段的解码值和简短说明。
- **买卖盘档位**：适用于 MBP-1/MBP-10、BBO、CBBO 和 CMBP 记录，每一档显示数量以及笔数（或交易所）。
- **重建此刻的订单簿（MBO）**：重放同一品种在这一行之前所有已载入的 MBO 记录，显示截至这一行的订单簿：
  价位、数量和挂单笔数。
  - 如果筛选条件可能漏掉了更早的消息，会显示警告（见 [4.2](#42-筛选与-mbo-订单簿)）。
  - 如果文件开头没有清簿（`R`）或快照，也会显示警告，因为文件开始之前就已存在的挂单不在簿中。
- **原始字节**：记录的十六进制字节，按字段着色，并附字节布局表（偏移、字段、类型、原始值）。记录为小端序。

### 5.3 图表

从列表中选择品种，或输入 instrument_id，然后选择：

- **图表类型**：K 线、报价、订单流、订单簿热图或价格线。
- **周期**：自动，或 1s 到 1W。
- **来源**：自动、成交或报价 mid。

品种的记录不支持的图表类型会被禁用。默认图表取决于记录类型：

- OHLCV 和成交数据打开为 K 线。
- MBO 和 MBP-10 打开为热图。
- 报价类 schema 打开为报价图。

| 图表 | 显示内容 |
|---|---|
| **K 线** | OHLCV 记录直接绘制，也可以合并为更粗的周期。含成交的记录（trades、tbbo、mbp、cmbp、mbo 中的成交）会聚合成 K 线，附总成交量以及按主动方区分的买卖量。只有报价的数据用中间价生成 K 线，此时成交量为报价笔数。附加面板显示 CVD（累计成交量差）、成交量分布和 VWAP。 |
| **报价** | 买价和卖价阶梯线，带阴影价差带和中间价。副图显示价差和盘口失衡 `(买量 − 卖量) / (买量 + 卖量)`。成交以气泡形式叠加。 |
| **订单流** | 成交气泡：大小表示成交量，绿色表示主动买入，红色表示主动卖出。另有每根 K 线的主动买卖量、CVD 和成交量分布。 |
| **订单簿热图** | 各价位挂单量随时间的变化，使用对数色阶：绿色为买方，红色为卖方。MBP-10 直接读取档位；MBO 会重放为订单簿，并按时间分箱采样。上面叠加最优买卖价线和成交。 |
| **价格线** | 记录中每个价格字段随时间的变化，以及每分钟记录数。序列较长时按最小/最大值降采样。 |

**技术指标**（仅 K 线）：图表上方的 **技术指标** 按钮会打开一个菜单。

| 类别 | 指标（默认参数） |
|---|---|
| 叠加在价格图上 | SMA（20）、第二条 SMA（50）、EMA（20）、布林带（20, 2）、VWAP（累计，典型价格） |
| 独立副图 | RSI（14）、MACD（12, 26, 9）、ATR（14）、随机指标 Stochastic（14, 3） |

- 默认启用两条 SMA。
- **指标参数…** 用于修改周期，**全部清除** 会移除所有指标。
- 选择和参数都会被记住。
- 指标基于当前显示的 K 线计算，需要足够的 K 线后才开始出现（例如 SMA 20 需要 20 根）。

图表操作：

- 滚轮或双指捏合缩放，拖动平移。
- 图表上方的十字光标读数显示光标所在位置的数值。

### 5.4 统计

统计标签页显示：

- 符合筛选的记录数和已读记录数、品种数量和时间范围
- 按记录类型、action 和 side 的分布
- 按行数排名前 200 的品种

最活跃品种的每一行都有两个链接：**筛选** 会只针对该品种重新扫描，**图表** 会在图表标签页中打开它。
扫描进行中，或因达到行数上限而停止时，这些数字只覆盖已读取的部分。

### 5.5 格式说明

格式说明标签页解释当前打开的文件：

- **schema 的含义**：每一行代表什么。
- **数据分层**：zstd 外层、元数据头和定长记录。
- **元数据头**：字节映射，列出本文件的实际值和偏移。
- **记录布局**：每个字段（包括填充字节）的偏移、大小、类型和含义。
- **枚举值含义**：action、side、flags 各位、`stat_type` 以及表示未定义的哨兵值。
- **常见陷阱**：例如价格是整数 ÷ 1e9、`ts_recv` 与 `ts_event` 的区别、MBO 中 `T`/`F` 与 `C`/`M` 的区别，
  以及 OPRA 的 instrument id 每天可能不同。

### 5.6 MBO 订单簿回放

**工具 → MBO 订单簿回放…**（⇧⌘R，仅限 MBO 文件）打开一个窗口回放当天的订单簿。起点是表格中选中的行（取它的品种和
接收时间）；纳斯达克的日文件默认从纽约时间 09:30 开始。

- **档位**（左侧）：每边前 *档数* 档的数量条和挂单笔数，刚变化的档位会闪一下。勾选 **显示队列（L3）** 后，每根数量条
  按队列顺序拆成一笔笔挂单（排在最前的紧挨价格），鼠标悬停可看到队列位置、订单号和数量。
- **图表**（右上）：买价、卖价阶梯线和成交点（点的大小代表成交量，颜色代表主动方向），窗口随当前时间移动；点击图表
  可跳到那个时间。
- **事件流**（右下）：当前位置之前的 40 个事件，最新的在最上面。
- **播放**：▶ / 空格键按所选速度（0.1× 到 1800×）播放；←/→ 前后一秒，⇧←/⇧→ 前后一个事件；拖动时间轴或在时间框输入
  （`10:30`、`10:30:15.250` 或完整日期时间）可跳到任意位置。

两种引擎：

- **LOB-WASR**（[github.com/chester1uo/LOB-WASR](https://github.com/chester1uo/LOB-WASR)）：0.6.1 起的安装包已内置；从源码运行时需安装 `wasr` 包
  （`pip install "dbnview[replay]"`，会从源码编译，需要 C++17 编译器、CMake 和 libzstd）。第一次回放某个文件时会把它
  索引成缓存目录里的 `.wasr` 文件（macOS 为 `~/Library/Caches/DBNView/wasr`，Windows 为
  `%LOCALAPPDATA%\DBNView\cache\wasr`，Linux 为 `~/.cache/dbnview/wasr`；可用 `DBNVIEW_CACHE_DIR` 覆盖），1000 万个
  事件的一天大约 5 秒，之后打开是瞬间的。跳到任意时间只需几毫秒，播放每帧远低于 1 毫秒，队列完全精确（包括 CME 的
  modify 规则）。远程文件会先下载到缓存再建索引。LOB-WASR 要求每个文件只有一个品种。
- **已加载的行**：没有安装 wasr（或文件含多个品种）时使用。回放扫描已加载的某个品种的 MBO 行，在内存中保存
  checkpoint。只覆盖已加载的行（*最多行数*），队列顺序为近似（modify 会把订单移到队尾）。

## 7. IV 曲面

IV 曲面标签页适用于使用 OSI 格式代码的期权数据，也就是 OPRA 的 `raw_symbol` 格式：

```text
SPY   260116C00690000   root padded to 6 chars + YYMMDD + C/P + strike × 1000 (8 digits)
```

即：标的代码补足 6 个字符 + 到期日 YYMMDD + C/P + 行权价 × 1000（8 位数字）。

适用的文件包括 OPRA cbbo-1s/1m、cmbp-1、tcbbo、bbo、trades 和 ohlcv。扫描结束后，DBNView 会检查是否至少有
一半的品种使用 OSI 代码。如果是，就填充 **标的** 列表，合约最多的标的排在最前。

### 7.1 控件（桌面）

| 控件 | 默认值 | 含义 |
|---|---|---|
| 标的 | 合约最多的标的 | 要计算的期权标的代码 |
| 时间 / 滑块 | 已载入数据的最后时间 | 快照时间。可以直接输入（格式与筛选相同），也可以在已载入的时间范围内拖动滑块。 |
| 标的价格 | 留空（自动） | 可选的现价。只用于无法通过平价关系得出远期价格的到期日。 |
| r | 4 % | 连续复利无风险利率 |
| 期权 | 虚值 (OTM) | 使用哪些报价：OTM、Call、Put 或 Call + Put |
| X 轴 | ln(K/F) | 对数价值度（log-moneyness）、行权价 K 或 call delta |
| 最大价差 | 50 % | 丢弃 (ask − bid) / mid 超过此值的双边报价 |
| 最短到期 | 2 天 | 跳过距到期时间短于此值的到期日 |
| 报价时效上限 | 30 分钟 | 丢弃最后一次更新早于此时长的合约（0 = 不限） |

点击 **计算**。然后可以使用以下视图：

- **3D 曲面**：
  - 拖动旋转。
  - 滚轮或双指捏合缩放。
  - 中键拖动或 ⌘+拖动（Windows 和 Linux 上为 Ctrl+拖动）平移。
  - 用按钮切换俯视、正视、侧视，重置视角，以及放大和缩小。
- **热图**：单击某个单元格，即可把对应的到期日和 x 值选为截面。
- **到期日列表**：勾选到期日以绘制其**波动率微笑**。圆圈为 call，三角为 put，竖线表示买卖价对应的 IV 区间。
- **期限结构**：各到期日在固定 x 处的 IV，例如平值 `ln(K/F) = 0`、固定行权价或固定 delta。
- **导出 CSV…**：每个 IV 点一行，列为 `sym, iid, exp, days, cp, K, F, k, delta, bid, ask, mid, iv, iv_bid, iv_ask, age_s`。

终端界面的 IV 标签页（按键 `6`）用固定设置计算合约最多的标的：r = 4 %、OTM、最大价差 50 %、最短到期 0.5 天、
报价时效上限 30 分钟。在输入框中输入时间并按 Enter。它会显示各到期日在固定 `ln(K/F)` 分组处的 IV，
后面再附一张平值期限结构图。

### 7.2 计算方法

1. **快照**：对每个合约，取所选时间点或之前的最后一条记录。
   - 报价为双边（bid > 0 且 ask ≥ bid）时，价格取买卖**中间价**。
   - 否则取最新成交价：`price`，OHLCV 则取 `close`。
   - 如果已载入的行没有覆盖到所选时间（扫描设置了筛选，或因达到行数上限而停止），就改为从文件开头流式读取到
     该时间，并显示进度。
2. **到期时间**：到期时刻取到期日当天 America/New_York 16:00，T = (到期时刻 − t) / 365 天。折现因子 D = e^(−rT)。
3. **各到期日的远期价格（买卖权平价）**：
   - 在同时有 call 和 put 中间价的行权价中，取 |C − P| 最小的 5 个。
   - 对每个行权价计算 F = K + (C − P) / D，取中位数。
   - 如果没有同时有 call 和 put 的行权价：填写了标的价格时 F = S·e^(rT)，否则跳过该到期日。
4. **隐含波动率**：Black-76，用向量化二分法在 [0.01 %, 600 %] 区间内求解。
   - 超出无套利区间的价格（不高于内在价值，或不低于上界）不计算 IV。
   - 用同样的方法计算买价和卖价对应的 IV，作为微笑图中的误差线。
5. **报价选择**：OTM 在 K ≥ F 时用 call，在 K < F 时用 put。然后按最大价差、最短到期和报价时效上限丢弃报价。
6. **曲面网格**：
   - 每个到期日在统一的 x 网格上做线性插值。对数价值度网格裁剪到 [−1, 1]。
   - 最多绘制 40 个到期日。

### 7.3 注意事项

- **仅支持 OSI 代码**：无法识别期货期权和其他 symbology。
- **到期时刻**：到期时刻固定为纽约时间 16:00。AM 结算的合约（例如 SPX 月度期权）实际上会早几个小时到期，
  这对临近到期的合约影响较大。
- **用欧式模型处理美式期权**：Black-76 是欧式模型，而美国股票期权是美式期权。
  - 选择虚值合约可以让提前行权溢价保持较小。
  - **Call** / **Put** / **Call + Put** 会包含实值报价，它们的 IV 可能有偏差。
- **单一利率**：r 是一个固定数值。股息和借券成本会体现在各到期日的平价远期价格中，不单独建模。
- **陈旧和价差过大的报价**：
  - cbbo-1m 等采样类 schema 的报价本身最多可能滞后 60 秒。
  - 用 **报价时效上限** 和 **最大价差** 剔除流动性差的合约。
  - 只有成交的数据（trades、ohlcv）得到的 IV 噪声较大。
- **流式读取的开销**：流式读取到已载入范围之外的时间点，会从文件开头开始读，对一整天的 OPRA 数据可能需要几分钟。

## 9. 浏览器界面

```bash
dbnview-web [DIR_OR_FILE ...] [--port 8765] [--head N]
```

| 选项 | 含义 |
|---|---|
| `--port` | 首先尝试的端口（默认 8765）。如果被占用，会依次尝试后面 19 个端口。 |
| `--host` | 绑定地址（默认 `127.0.0.1`）。建议保持默认，远程访问时使用 ssh 隧道。 |
| `--no-token` | 关闭访问令牌（不推荐） |
| `--open` | 打开浏览器标签页 |
| `--head N` | 打印给定的每个文件的前 N 条记录后退出，不启动服务器 |
| `--tz` | `--head` 输出使用的时区（默认 `America/New_York`） |

**安全性**：

- 服务器只绑定在 localhost 上。
- 它会输出一个带随机 `?token=…` 的 URL。没有令牌、也没有首次访问时设置的 cookie 的请求都会被拒绝。

**在服务器上使用**：这是查看服务器上数据的常用方式。

```bash
# on the server (only numpy + zstandard are needed)
dbnview-web /data/databento
# on your laptop
ssh -N -L 8765:localhost:8765 myserver
# then open the printed http://localhost:8765/?token=... in a local browser
```

即：在服务器上启动 `dbnview-web`（只需要 numpy 和 zstandard），在笔记本上建立 ssh 隧道，然后在本地浏览器中
打开输出的 URL。

**单文件版本**：如果无法在服务器上安装包，可以在克隆的仓库中构建一个 zipapp：

```bash
python tools/build_web_pyz.py           # writes dist/dbnview-web.pyz
scp dist/dbnview-web.pyz myserver:
ssh myserver python3 dbnview-web.pyz /data
```

**页面提供的功能**：

- 文件浏览器、文件元数据、与桌面应用相同的筛选条件，以及可跳转到指定时间的记录表格
- 带原始字节的行详情，以及 MBO 订单簿重建
- 价格线图表、统计、格式说明和 CSV 导出

页面文字目前只有繁体中文。桌面应用和终端界面支持全部 7 种语言。

## 12. 正确性与性能

- **格式**：支持 DBN v1、v2 和 v3，根据文件头自动选择布局。更新的版本会被拒绝，并给出明确的错误提示。
- **记录布局**：来自官方 `databento_dbn` 的定义，枚举值含义已对照 databento.com/docs 核对。
- **已与官方解码器比对**：解码器在 CME MBO（v3）、OPRA cbbo-1m（v1）和 OPRA cmbp-1（v1）上与 Databento
  官方解码器逐字段比对，所有字段完全一致。
- **未定义值**：表示“未定义”的整数哨兵值显示为 `—`。价格用 INT64_MAX，时间戳用 UINT64_MAX，数量用 UINT32_MAX。
- **吞吐量**：约每秒 500–600 万条记录。解压在后台线程中进行，同时解析记录。
- **大文件**：zstd 无法随机定位，所以每次扫描都从文件开头开始。用筛选条件缩小扫描范围；只有需要完整统计时
  才使用 **扫描完整文件**。

## 13. 故障排查

| 问题 | 解决方法 |
|---|---|
| macOS 提示应用“无法打开”或已损坏 | 自行构建的应用只有 ad-hoc 签名，没有经过公证。在 Finder 中右键单击应用 → **打开**（只需一次），或运行 `xattr -cr /Applications/DBNView.app`。 |
| Linux：`qt.qpa.plugin: Could not load the Qt platform plugin "xcb"` | 安装 Qt xcb 库，例如 `sudo apt install libxkbcommon-x11-0 libxcb-cursor0 libegl1`。也可以改用 `dbnview-tui` / `dbnview-web`。 |
| 打开远程文件时报 `Permission denied`、`Host key verification failed` 或超时 | ssh 以 BatchMode 运行，无法进行任何询问。先在终端中运行 `ssh HOST true`，它必须无需任何交互就成功（接受主机密钥、把密钥加入 agent、检查 `~/.ssh/config`）。 |
| 远程目录列表为空或失败 | 远程机器需要 GNU `find` 和 `stat`（Linux）。确认使用的是绝对路径。 |
| 扫描在 1,000,000 行处停止 | 这是行数上限。可以调高 **最大行数**、缩小筛选范围，或勾选 **扫描完整文件** 以获得完整统计。 |
| 大文件要很久才能读到下午的数据 | 扫描总是从开头开始。加上时间筛选，只保留需要的行。对于远程文件，可以考虑在数据所在的机器上运行 `dbnview-web`。 |
| 订单簿看起来不对 | 见 [4.2](#42-筛选与-mbo-订单簿)。去掉起始时间、action/side 或 `where` 筛选后重新扫描。开头没有清簿或快照的文件，会缺少文件开始之前就已存在的挂单。 |
| `DBN vN is not supported yet` | 文件使用的 DBN 版本高于 3。 |
| `pip install zstandard` 错误 | 引擎需要 `zstandard` 才能读取 `.zst` 文件。请重新安装本包。 |
| IV 标签页提示文件不是期权数据 | 在映射中找不到 OSI 期权代码（见 [7.3](#73-注意事项)）。 |
